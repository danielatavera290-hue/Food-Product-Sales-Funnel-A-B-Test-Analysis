# Food Product Sales Funnel & A/B Test Analysis

---

## Dataset
The dataset contains event logs generated by users interacting with the application.

Main columns include:

- User ID
- Event name
- Timestamp
- Experiment group

---

## Project Structure

1. Data loading
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Event funnel analysis
5. A/B test analysis
6. Statistical hypothesis testing
7. Business conclusions and recommendations

---

## Tools & Technologies

- Python

---

## Key Insights

- No statistically significant differences were found between the control groups, indicating that the experimental split was correctly performed.
- The experimental strategy did not generate significant improvements in user behavior or conversion rates.
- The largest user drop-off occurs at a specific stage of the funnel, suggesting an opportunity for optimization.
- Future strategies should focus on improving conversion at the most critical funnel stage.

---

## Statistical Methods

The project includes:

- Funnel conversion analysis
- Proportion comparison tests
- Hypothesis testing for A/B experiments
- Significance evaluation using p-values
